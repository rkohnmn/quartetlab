# Organic Distribution and Launch Plan.

QuartetLab supports organic search growth and peer sharing among statistics teachers, STEM instructors, and data analysts.

## 1. Built-In Product Growth Loops.

1. **Zero-Backend Shareable Dataset Links (`#state=...`).** Teachers can sculpt a custom dataset and copy a self-contained link. When a colleague or student opens that URL on GitHub Pages, QuartetLab loads the exact point cloud and regression diagnostics right away.
2. **Printable Classroom FRQ Handouts.** Printed worksheets include a subtle `QuartetLab Worksheet Studio` header line. Departmental exam packets act as natural peer sharing touchpoints.
3. **Multi-Tool Code Exports.** Exported R (`lm`), Python (`scipy.stats`), TI-84 (`L1/L2`), and LaTeX (`booktabs`) snippets include a comment line noting the QuartetLab summary moments.

## 2. Target Communities and Launch Channels.

1. **Reddit Math and AP Communities (`r/matheducation`, `r/APStudents`).** Reach high school AP Statistics and math teachers who need Minitab regression output tables, TI-84 `L1/L2` lists, and printable FRQ rubrics.
2. **Statistics and Data Science Forums (`r/statistics`, `r/datascience`).** Reach college instructors and analysts who want a Gram-Schmidt solver that projects any drawn shape onto exact $(\bar{x}, s_x, \bar{y}, s_y, r)$ moments.
3. **Physics Lab Communities (`r/PhysicsTeachers`).** Reach high school and college lab teachers who teach linearization ($T^2$ vs. $L$) with residual plots and Cook's Distance flags.
4. **GitHub Topics and Open Lists.** Publish under open-source topics (`statistics`, `anscombe-quartet`, `ap-statistics`, `regression-diagnostics`).

## 3. Search Intent and SEO Positioning.

QuartetLab targets five high-intent utility searches where older tools fall short.

1. `"draw my data exact correlation generator"`.
2. `"AP statistics computer regression output table generator"`.
3. `"interactive Anscombe's quartet residual plot applet"`.
4. `"Cook's distance and hat value interactive visualizer"`.
5. `"TI-84 linear regression list generator for teachers"`.

## 4. Evidence-Graded Content Packaging.

Launch posts skip generic marketing claims. Each post opens with a 15-second screen capture. The clip shows a user dragging a single high-influence point at $(19, 12.5)$ while the OLS line pivots, Cook's Distance crosses $4/n$, and the Minitab table updates live.
